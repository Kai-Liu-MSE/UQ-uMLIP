# ACE Potential Dataset for UQ Analysis

This repository provides ACE (Atomic Cluster Expansion) potential functions trained using both DFT data and uMLIP distillation data. 

Five ACE potentials are included in each dataset for uncertainty quantification (UQ) analysis.

Scripts are provided to show how to use the potential in LAMMPS.
